# lab6-bribeiro2021
lab6 starter repository for bribeiro2021

## Features
- [ ] Create an account and log in using Firebase Authentication
- [ ] Send and receive messages using Firebase Firestore
- [ ] View messages in real time across multiple devices
- [ ] Distinguish sent and received messages using different colors and positions
- [ ] Stay logged in between app sessions
- [ ] Sign out of your account
- [ ] Display the user's email at the top of the chat
- [ ] Show timestamps for each message
- [ ] Clear chat history
